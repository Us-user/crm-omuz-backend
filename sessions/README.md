# Журнал сессий разработки

Здесь хранится история работы над проектом. Каждая рабочая сессия (обычно один запуск команды `/start`) оставляет **один файл-лог**. Это «память» проекта между сессиями Claude Code.

## Как это работает
1. Команда `/start` читает `ROADMAP.md` и **все** файлы из этой папки по порядку (по имени), восстанавливая контекст: что уже сделано и где остановились.
2. Выполняет следующий незакрытый пункт roadmap.
3. Создаёт новый файл-лог сессии здесь.
4. Обновляет чекбоксы в `ROADMAP.md`.
5. Коммитит и пушит на GitHub.

## Правила именования
`NNNN-краткое-описание.md`, где `NNNN` — порядковый номер с ведущими нулями.
Пример: `0001-auth-module.md`. Номер всегда возрастает — так файлы читаются по порядку.

## Формат
Каждый лог — копия `SESSION_TEMPLATE.md`. Заполняется в конце сессии: что сделано, какие
решения приняты, что осталось, следующий шаг. Пиши по факту — если что-то не доделано или
не проверено, честно это отметь.
